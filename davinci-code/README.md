# 达芬奇密码 · 人机对战(Da Vinci Code)

一个纯前端、零依赖的「达芬奇密码」推理小游戏,支持与 AI 对战。仿照 [game.hullqin.cn/dfqmm](https://game.hullqin.cn/dfqmm) 的玩法,严格实现原版规则,界面清晰易懂。

界面采用「文艺复兴 · 绿绒桌 + 金箔」的桌游质感:立体质感的黑/白实体牌、衬线数字、翻牌动画,并内置<b>浅色/深色主题切换</b>(默认跟随系统)。

## 玩法

打开 `index.html` 即可游玩(无需任何构建、无需联网)。

- 你和 AI 各拿 **4 张暗牌**,数字 **0–11** 各有黑、白两张,共 24 张。
- 手牌必须**从小到大**排列;数字相同时,**黑色在左、白色在右**。
- 轮到你时:
  1. 从**黑堆或白堆选一种颜色抽一张**牌(先拿在手上,不公开)。
  2. **猜对方一张暗牌的数字**(必须猜一次)。
  3. **猜中** → 对方那张牌翻开,你可以**继续猜**或**停手**。
  4. **停手** → 把抽到的牌暗插进自己手牌,回合结束。
  5. **猜错** → 你抽到的那张牌被翻开,回合结束(牌堆空时改为自选一张自己的暗牌翻开)。
- 当一方所有牌都被翻开时,该方输,另一方获胜。

## AI 对战

内置三档难度:

| 难度 | 行为 |
|------|------|
| 简单 | 只做一次合法猜测,不连猜,常常放过必胜机会 |
| 普通 | 优先猜「唯一确定」的牌,并做概率最高的猜测,命中率 ≥50% 才冒险连猜 |
| 困难 | 枚举所有合法排列做**约束求解**,用真实频率估算概率,吃满所有确定项并在 ≥34% 时冒险连猜 |

AI 的推理只用「公开信息」:所有已翻开的牌、暗牌的颜色与位置、以及排序规则,通过回溯枚举每个暗牌位置的可能数字集合——和真人一样,不会偷看你的暗牌。

